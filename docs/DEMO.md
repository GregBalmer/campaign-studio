# Demo video script (2–3 minutes)

The video has one job: show the required pipeline working, in the assignment's order, with a person approving the decisions that matter. Record at 1440×900, the browser full-screen. Target: about 3:00.

**Before recording:** start the app once and sign in. Click **Restart demo** beside the campaign name. Open **Services** and check **OpenAI** is selected for images and translation, and that **Azure Blob Storage** is connected. Then stop the app (close its window), so it starts on camera. Have a terminal open in the project folder, and the README open on GitHub.

| Time | Screen | Say |
|---|---|---|
| 0:00 | README on GitHub | "This is Campaign Studio. One brief in, every social ad out, in every size and market, with a person approving the decisions that matter." |
| 0:12 | Terminal | Run `python3 start.py`. "Setup is one command, or a double-click if you'd rather not use a terminal. It installs what it needs the first time and opens the browser. It all runs on this computer." If it asks, click **Sign in**: the demo account is filled in. |
| 0:22 | Brief | "It opens on a sample: two products, two markets, one message. One product has a photo, so we'll reuse it. The other doesn't, so we'll generate it. The panel on the right says what we'll get: twelve ads." |
| 0:47 | Click **Create key visuals** | "Nothing gets resized or translated yet. First, one key visual per product, for a person to approve." |
| 0:57 | Key visual: photo | "This is the client's photo. I fit the box around the product; every size is cropped around it. The outlines show where the Story and Banner crops land, and the previews update live." Approve. |
| 1:17 | Key visual: generated | "This one was generated by OpenAI from the brief in about ten seconds. If it's wrong, **Try another** costs one image, not twelve ads." Fit the box. Approve. |
| 1:37 | Message | "The line is adapted for Japan, not just translated, and here's what it means in English, so I can sign off without reading Japanese." Type a restricted word to show the flag, then undo. "Legal's restricted words are caught before anyone approves." Approve both. |
| 2:02 | Review | "Twelve ads. Every one has been checked for legibility, logo, brand colors, restricted words, and whether the product is cropped or covered. Problems are marked on the ad itself." Open the flagged one. "It says what's wrong and how to fix it." |
| 2:27 | **Approve all that pass**, **Download**, **Show folder**, then **Send to Azure** | "Approve, download. Here's the folder: by product, then by size, with a report of who approved what and when. And one click sends the approved ads to the client's Azure storage, in the same folders." |
| 2:50 | Services panel | "Images, translation and storage are each chosen here: demo, OpenAI or Adobe Firefly for images. The Firefly adapter is written to Adobe's documentation and tested against a stand-in, not yet on a live account." |

**If anything fails on camera:** the app explains the error in plain words. That's worth keeping in the take.
